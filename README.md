三渲二角色动起来才完整：绑定、权重与动画的入门避坑指南
三渲二角色做静帧好看不难，难的是动起来不崩。卡通比例、描边、色块阴影和夸张表情，对绑定与权重的要求和写实角色很不一样。很多新手把模型绑完就直接做动画，结果一动就穿模、线宽乱跳、表情变形。下面按流程拆解入门阶段最容易踩的坑。

一、绑定前先定比例和关节位置。 三渲二角色常有大头、短肢、粗手脚，不能照搬写实骨骼位置。关节要对准实际旋转中心，短肢的权重过渡区反而要留宽一些，否则弯曲时像折断。绑定前先做几个极限姿势草图：抬臂、下蹲、转头、叉腰，确认模型有没有预留活动空间。衣服和身体之间要留间隙，裙摆、披风、长袖不能只靠身体权重带动。骨骼命名和层级提前规划，左右后缀统一，变形骨和控制器分开，后面做动画才不混乱。

二、权重：卡通角色要“硬中有软”。 自动权重后必须手动清理。常见问题是抬腿时肚子被拉走、转头时脖子塌陷、手臂弯曲时肩膀缩成一团。破解方法是限制每个顶点的影响骨骼数量，清理跨区域污染权重。卡通角色需要保留体积感：该硬的地方硬，比如护甲、鞋底；该软的地方软，比如脸颊、布料。不要全身平滑过渡，否则动起来像橡皮泥。权重测试动作要固定：抬臂、弯腰、转头、下蹲、交叉腿，每次绑定后跑一遍。腋下、肘部、膝盖、胯部是穿模重灾区，要重点检查。

三、面部和头发要独立控制。 三渲二角色的辨识度在脸。眼睛、睫毛、嘴线、眉毛最好用独立片或独立骨骼控制，不要全绑在头骨上。表情测试要做极限动作，检查嘴角、眼睑和眉毛是否拉变形。卡通表情幅度大，可以配合形态键或挤压拉伸骨，但不能靠权重硬拉。头发要分束绑定，大束用骨骼，小碎发用少量辅助骨或形态键，避免转头时头发穿脸或整片僵硬。刘海和侧发要检查与面部、肩膀的穿插。

四、服装和配件别全绑身体。 外套、裙摆、披风、腰带、挂饰要有独立骨骼或简单物理模拟。全绑在身体上，一动就穿模或拉扯变形。硬质配件如护甲、武器、背包要绑定到对应骨骼，但注意不要和身体权重混在一起。裙摆至少加两到三根辅助骨，走路和转身时能分层摆动。袖口和裤脚要留活动余量，弯曲时不能把布料拉成尖角。

五、动画测试要结合渲染镜头。 绑定权重没问题，动画仍然可能出问题：脚部滑步、重心发飘、动作卡顿。先做关键姿势，再调节奏；走路和跑步要检查脚部接触帧是否滑动。卡通动画可以夸张，但重心和惯性要合理，挤压拉伸要服务于动作。更重要的是按实际播放分辨率检查：描边线宽是否跳动、阴影是否闪烁、小纹理是否糊成噪点。动画幅度大时简化材质细节，描边和阴影参数尽量稳定，不要每帧变化。

六、三渲二特有的联动坑。 描边依赖模型法线和镜头距离，动画中极限姿势可能让线宽突变，要做遮罩和衰减。阴影色阶在动作中要统一，脸部阴影单独处理，避免鼻影和眼窝连成一片。边缘光在转身时不能突然爆亮或消失。头发和衣服的描边要控制粗细，避免和身体描边糊在一起。单帧好看不够，连续播放时轮廓要清楚、色块要稳定。
